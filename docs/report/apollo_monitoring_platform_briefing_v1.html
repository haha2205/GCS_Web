02

软件架构图

图中按数据源层、接入层、计算层、服务层和应用层组织，能够直接对应当前项目中的接入、建模、评测与展示主链。

页面说明

  • 接入层负责遥测链路监听、上行指令校验、协议解析与统一时间基准构建，是多源报文进入系统的入口。
  • 计算层围绕任务会话上下文重构和多模态异构数据融合组织任务级数据对象，为后续评测和架构比较提供统一输入。
  • 服务层承接动态运行效能在线评估、DSM 架构耦合分析和软硬件映射寻优，应用层再把结果回送到监控、分析与数据服务界面。
